# 心佑云端官网

成都高新心佑云端医疗美容诊所官方网站源文件。

## 部署

Cloudflare Pages 接入本仓库，配置如下：

| 配置项 | 值 |
|---|---|
| 框架预设 | None |
| 构建命令 | 留空（不要填任何内容） |
| 构建输出目录 | `/` 或 `.` |
| 生产分支 | `main` |

## 目录结构

```
.
├── index.html          官网主页面（含 MedicalClinic 结构化数据）
├── robots.txt          放行全部搜索引擎与 AI 爬虫
├── sitemap.xml         站点地图
├── _headers            Cloudflare Pages 响应头与缓存配置
└── img/                17 张图片（已压缩，最大边 1280px）
```

## 重要约束

- **根目录必须是 `index.html`**，图片必须在 `img/` 子目录下 —— Cloudflare Pages 按此路径解析，改层级会全部 404
- 修改内容后需保持NAP 信息三处一致：机构全称、电话 `19180811520`、地址（用「西段」不用「西端」）
- 新增页面后同步更新 `sitemap.xml`
